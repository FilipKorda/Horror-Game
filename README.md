## 🩸 About the Project

Haunted House is a first-person horror game set inside a dark, two-story abandoned house.
The player must complete 3 objectives before escaping, while being constantly hunted by a vampire roaming the house.
The game focuses on atmosphere, darkness, sound design, exploration and fear.

---

# 🏚️ Gameplay

The main objective is simple:

Complete all three tasks and escape the house before the vampire finds you.

The player needs to explore both floors of the house while searching for objects, completing objectives and finding a way to progress.

At the same time, the vampire constantly searches the environment for the player.

# 🎯 Objective System

The player must complete **three main objectives** before they can escape the house.

# 🧛 Vampire AI

The vampire is the main threat throughout the game.

# 😨 Fear System

Fear is one of the main gameplay mechanics.

The player's psychological state is affected by the events happening inside the house.

# 🔦 Flashlight System

The flashlight is one of the player's most important tools.

The house is extremely dark, making visibility limited without a light source.

# 🔋 Battery Management

Flashlight batteries are interactive items that can be discovered throughout the house.

# 💊 Medicine

Medicine can be discovered and collected during exploration.

Its main purpose is to reduce the player's current fear level.

# 👣 Audio & Atmosphere

Sound plays a major role in the horror experience.

# ❤️ Dynamic Heartbeat

The player's heartbeat is an important part of the fear system.

As tension increases, the heartbeat contributes to the feeling that something is wrong.

# 🫁 Breathing System

The player's breathing is another layer of immersive audio.

It helps communicate the player's physical and psychological state while exploring the house.

# 👣 Footstep System

The game includes separate footstep audio for both the player and the vampire.

# 💥 Jump Scare System

The game contains dedicated **jump scare mechanics** designed to surprise the player during exploration.

# 🖐️ Interaction System

The player can interact with objects throughout the house.

# 📖 Tutorial

The game contains a small tutorial introducing the player to the game.

# 🧩 Core Gameplay Loop

The game revolves around a continuous cycle of exploration, progression and survival.

```text
EXPLORE - FIND OBJECTS - COMPLETE OBJECTIVE - VAMPIRE APPEARS - RUN - MANAGE FEAR - USE ITEMS - CONTINUE EXPLORING - COMPLETE ALL TASKS - ESCAPE
```

# 🎯 Project Goals

The main goals of the project are:

* creating an atmospheric first-person horror experience
* developing an enemy capable of searching for and chasing the player
* creating a functional fear system
* building an extensive environmental audio system
* implementing immersive player audio such as breathing and heartbeat
* creating a resource-based flashlight system
* implementing interactive items
* designing a multi-floor horror environment
* implementing objective-based progression
* creating a jump scare system
* supporting keyboard, mouse and gamepad controls
* implementing persistent save/load functionality
* creating a clear and immersive UI/UX
